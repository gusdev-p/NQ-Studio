NQ-Studio

A simple IDE/Code Editor for JavaScript, HTML, CSS and Node.js projects :0

Tired of using a heavy IDE for a simple project? NQ-Studio is for you.

Features:

HTML Preview

Preview your HTML projects directly inside the editor.

Markdown Preview

Read your READMEs and Markdown files directly inside the editor.

Integrated Terminal

Run your commands without leaving the editor.

Makefile Support

View variables and targets, and run Makefile targets directly from the editor.

Interested? Take a Look!
